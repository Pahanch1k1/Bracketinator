# 🔍 Проверка скобочной последовательности

Программа для проверки корректности скобочных последовательностей `( ) [ ] { }`.

## 📌 Что делает программа

Проверяет, правильно ли расставлены скобки в введённой строке:
- Каждая открывающая скобка должна иметь закрывающую того же типа
- Скобки должны закрываться в правильном порядке (LIFO)
- Допустимые символы: `( ) [ ] { }` и пробелы
- При ошибке выводится позиция первого нарушения
